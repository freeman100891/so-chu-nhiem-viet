# Thư viện ảnh đại diện `custom_x`

1. Chép ảnh vào thư mục này và đặt tên bắt đầu bằng `custom_`, ví dụ `custom_5.png`.
2. Định dạng hỗ trợ: PNG, JPG, JPEG, WEBP, GIF hoặc SVG.
3. Thêm ảnh vào `gallery.json`:

```json
{ "file": "custom_5.png", "label": "Tên hiển thị" }
```

4. Trong form học sinh, bấm **Nạp thư viện** để làm mới danh sách.

Nên dùng ảnh vuông, kích thước 256–512 px và dung lượng dưới 300 KB.
